# M41 — 프로젝트 종료: tide로의 아이디어 이전과 종료 회고

## 목표

porpoise 저장소를 찾은 사람이 **이 프로젝트가 종료됐고 후속이 tide라는 것**을 README 첫 화면에서 알고,
tide 저장소·문서로 바로 이동할 수 있다. porpoise의 어떤 아이디어가 tide의 어떤 커맨드로 이어졌는지,
그리고 이 프로그램이 무엇이었는지가 커밋된 문서로 남는다. 종료 시점의 사용자 문서와 개발 문서가
실제 동작과 어긋나지 않는다.

## 배경

- v0.37.0 시점 retro(`docs/reports/retro.md` 최상단, 미커밋)가 "retro 두 뿌리(halt·비용)가 다 해소돼
  **다음 큰 방향이 비어 있음**"을 기록했다.
- 그 사이 porpoise의 개발 방법론(마일스톤 → 구현 → 리뷰 → 릴리즈)은 Claude Code 플러그인
  [tide](https://github.com/Jongh/tide)(v2.46.0)로 독립·성장했고, M37부터 porpoise 자신도 tide 체계로 개발됐다.
- 사용자 요청(2026-10-29): 프로젝트 종료 · tide로의 아이디어 이전 · tide 링크 연계로 README 정리, 그리고
  프로그램의 의미를 회고한 문서를 커밋 가능하게. 문서 전용 커밋 경로(`/tide:release docs`)의 허용 경로 밖이라
  정식 마일스톤으로 진행한다.
- 발견된 문서 결함: README "실행 모드" 표가 legacy를 기본·conductor를 실험적으로 적고 있으나 실제로는
  v0.22.0(M22)부터 claude_code 어댑터의 기본이 conductor다. `docs/project-context.md`·`docs/conventions.md`의
  현재 버전 표기도 `0.33.0`에 멈춰 있다(`Cargo.toml`은 `0.37.0`).

### M41-T01: README 종료 안내 · tide 링크 · 이전 매핑 표 + 실행 모드 표 정정

- **변경 파일**: `README.md`

  tide 저장소(`https://github.com/Jongh/tide`)·문서 사이트(`https://jongh.github.io/tide/`)·설치 명령
  (`/plugin marketplace add Jongh/tide` → `/plugin install tide@tide`)·종료 회고 링크, 기존 바이너리는 Releases에서 계속 제공.

- 실행 모드 표를 실제 동작(v0.22.0부터 claude_code 기본 conductor, legacy는 API 어댑터·비-git 폴백)에 맞춘다.
- 기존 사용법·CHANGELOG 절은 기록 보존을 위해 유지한다.

미커밋 산출물이라 git 기준으로는 이미 변경 상태다 — M41이 이를 정식화한다. `docs/reports/retro.md`의 미커밋 변경은
v0.37.0 릴리즈 뒤 회고 산출물로 이 마일스톤의 변경이 아니나, 같은 릴리즈 커밋에 실린다.

## 완료 기준

1. `README.md` 첫 화면(제목 직후 블록)에 다음 다섯이 모두 있다: 개발 종료 문구 · tide 저장소 URL · tide 문서 URL ·
   설치 명령 · `docs/retrospective.md` 링크.
2. README의 이전 매핑 표의 tide 커맨드가 tide 실물(`../tide/skills/` 디렉터리 목록)에 모두 존재한다.
3. README 실행 모드 표가 `src/config/workspace.rs`의 conductor 기본값 동작과 일치한다.
4. `docs/retrospective.md`의 수치(기간·커밋 수·태그 수·테스트 수)가 `git log`·`git tag`·`cargo test` 실측과 일치한다.
5. `docs/project-context.md`·`docs/conventions.md`에 `0.33.0` 버전 숫자 복제가 0건이고, 종료·tide 이전이 project-context 개요에 표기된다.
6. 문서 안 상대 링크(`README.md`·`docs/retrospective.md`의 `docs/…`·`reports/…`)가 모두 실재 파일을 가리킨다.
7. 코드 무변경 — `cargo build` 성공, `cargo test` 전체 통과.
